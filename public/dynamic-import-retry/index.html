Flaky import() Playground

Chrome 155 added -- without fanfare -- the ability to retry dynamic import() and failed module loads. This page is a basic demo for testing that. This already works in Firefox, and is pending release in Safari.

Use devtools and network throttling to simulate different conditions, and monitor fetches in the Network tab.

In Chrome 154 and earlier, there is a single fetch: if it fails then it is not repeated. In Chrome 155 and other browsers, the fetch will be retried if it failed initially.
